Import format

Student roster CSV: student_id, student_name, student_email, department, adviser_name, adviser_email, subject, teacher_name, teacher_email, classes_held, classes_attended.
Marks CSV: student_id, subject, assessment, date, score, max_score.
Timetable CSV: teacher_email, teacher_name, day, start_time, end_time, status (use available/free for bookable slots).

Upload one CSV at a time. Roster uploads replace the current roster; marks and timetable rows are added or updated. Matching uses student ID and teacher email.
